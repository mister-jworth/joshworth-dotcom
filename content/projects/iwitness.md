<h3>iWitness</h3>
Inspired by his experience making Schindler’s List, Steven Spielberg established what is now the Shoah Foundation Institute to gather video testimonies from survivors and other witnesses of the Holocaust.

The foundation's archive now contains over 52,000 hours of video in 32 languages, and has been indexed by time-code so if, for instance, a researcher is looking for a person speaking about potato rationing in the Warsaw ghetto, they can find it with a simple search tool. To make use of this amazing resource, the foundation set up iWitness, an online, educational tool that allows teachers and students to create lesson plans and class projects using the footage.

I was brought on in the middle of the project to help define the scope and create an intuitive site structure that would allow users to accomplish some fairly complex tasks in a short amount of time. I created detailed wireframes and page mockups for tools that would allow students to search the archive, edit together a video on a given topic, and share it with the class. I also designed an interface that would let teachers author lesson plans, communicate with classes and give feedback on student projects.

You can see the site at <a href="http://iwitness.usc.edu/SFI/" target="_blank" rel="noopener noreferrer">iwitness.usc.edu</a>, though you need to be affiliated with a school to access most of the features I had a hand in.</div>
