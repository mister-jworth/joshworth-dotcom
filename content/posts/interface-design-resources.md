For all my UX design friends out there, I thought I'd post links to a few of my favorite interface design resources.

<strong><a title="visit Konigi" href="http://konigi.com/" target="_blank" rel="noopener noreferrer">Konigi</a></strong>
<strong><a title="visit Konigi" href="http://konigi.com/" target="_blank" rel="noopener noreferrer"></a>A great site that catalogues an array of quality UI elements. They also have a page with some useful templates and <a title="Konigi's wireframing tools" href="http://konigi.com/tools/overview" target="_blank" rel="noopener noreferrer">tools for wireframing</a>, including a set of printable images you can use to create your own set of moveable magnets (in case you want to design a website on your fridge.)</strong>

<a title="visit Wireframes Magazine" href="http://wireframes.linowski.ca/" target="_blank" rel="noopener noreferrer"><strong>Wireframes Magazine</strong></a>
The design of every good website or interactive project begins with wireframes. A  fellow up in Canada, named Jakub Linowski, keeps a blog called Wireframes Magazine which offers some excellent advice for Information Architects. He also discusses the <a title="view the list" href="http://wireframes.linowski.ca/category/tools/" target="_blank" rel="noopener noreferrer">many tools</a> available for quickly generating early visual representations of interfaces.

<a title="visit Pattern Tap" href="http://patterntap.com/" target="_blank" rel="noopener noreferrer"><strong>Pattern Tap</strong></a>
Pattern Tap collects and organizes examples of web design interface elements. The site is broken down into helpful categories like navigation, tables, pagination, and breadcrumbs.</div>
